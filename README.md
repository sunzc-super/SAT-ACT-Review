# SAT-ACT anonymous code archive

## Data Preparation

Use the `medium` datasets generated by
[G4SATBench](https://github.com/zhaoyu-li/G4SATBench). Organize the CNFs by
family, split, and label:

```text
<g4satbench-root>/medium
├── ca
│   ├── train
│   │   ├── sat
│   │   └── unsat
│   ├── valid
│   │   ├── sat
│   │   └── unsat
│   └── test
│       ├── sat
│       └── unsat
├── sr
└── ps
```

This repository starts from those CNFs. `gen_data` captures solver states,
constructs candidate actions, evaluates their outcomes, and builds SAT-ACT
preference pairs. It does not generate the original CA, SR, or PS CNFs.

## Contents

- `gen_data`: action rollout, outcome evaluation, and pair construction.
- `neuro`: preprocessing, training, inference, configs, and checkpoints.
- `solver`: neural-assisted CaDiCaL, inference service, benchmark preparation,
  and solver evaluation.

## Environment and dependencies

See [ENVIRONMENT.md](ENVIRONMENT.md) for compiler, gRPC/Protobuf, Python, and
CUDA requirements.

Run all commands below from the repository root.

## Build

Build DecisionTrace inside `gen_data/cadical/build`:

```bash
# Build the DecisionTrace data generator.
cmake -S gen_data/cadical/src -B gen_data/cadical/build \
  -DCMAKE_BUILD_TYPE=Release
cmake --build gen_data/cadical/build --target decisiontrace -j 8
```

Build the neural-assisted solver inside `solver/build`:

`GRPC_PREFIX` is the installation prefix of the gRPC C++ and Protobuf C++
libraries, not a gRPC source directory. For example, if
`/opt/grpc-1.76.0/lib/cmake/grpc/gRPCConfig.cmake` exists, use
`/opt/grpc-1.76.0` as the prefix.

```bash
# Build the neural-assisted CaDiCaL solver.
GRPC_PREFIX=/opt/grpc-1.76.0
solver/build.sh solver/build "$GRPC_PREFIX" 8
```

## Generate action and pair data

The wrapper uses propagation horizon 1000 for CA, 5000 for SR, and 15000 for
PS. Run every split explicitly.

### CA

```bash
# Generate action and pair data for all CA splits.
G4SATBENCH_ROOT=/path/to/g4satbench
OUTPUT_ROOT=/path/to/satact-output

# Process the CA training split.
python gen_data/prepare_dataset.py all \
  --family ca --split train \
  --input-dir "$G4SATBENCH_ROOT/medium/ca/train" \
  --output-dir "$OUTPUT_ROOT/datasets/ca/train" \
  --binary gen_data/cadical/build/decisiontrace \
  --cache-dir "$OUTPUT_ROOT/cnf-cache/ca/train" \
  --workers 8 --seed 1

# Process the CA validation split.
python gen_data/prepare_dataset.py all \
  --family ca --split valid \
  --input-dir "$G4SATBENCH_ROOT/medium/ca/valid" \
  --output-dir "$OUTPUT_ROOT/datasets/ca/valid" \
  --binary gen_data/cadical/build/decisiontrace \
  --cache-dir "$OUTPUT_ROOT/cnf-cache/ca/valid" \
  --workers 8 --seed 1

# Process the CA test split.
python gen_data/prepare_dataset.py all \
  --family ca --split test \
  --input-dir "$G4SATBENCH_ROOT/medium/ca/test" \
  --output-dir "$OUTPUT_ROOT/datasets/ca/test" \
  --binary gen_data/cadical/build/decisiontrace \
  --cache-dir "$OUTPUT_ROOT/cnf-cache/ca/test" \
  --workers 8 --seed 1
```

## Train

For each family, `train` updates the model, `valid` is evaluated after training
epochs and selects the best checkpoint, and `test` reports the result of that
selected checkpoint at the end. The validation data is therefore consumed by
the training command through `--valid-dir`; it is not a separate data-generation
or solver-validation procedure.

### CA training

```bash
# Train the CA Base and Full models.
OUTPUT_ROOT=/path/to/satact-output
DEVICE=cuda

# Train SAT-ACT Base on CA.
python neuro/scripts/train_from_config.py \
  --config neuro/configs/ca_satact_base.json \
  --train-dir "$OUTPUT_ROOT/datasets/ca/train" \
  --valid-dir "$OUTPUT_ROOT/datasets/ca/valid" \
  --test-dir "$OUTPUT_ROOT/datasets/ca/test" \
  --cache-dir "$OUTPUT_ROOT/indexes/ca/base" \
  --output-dir "$OUTPUT_ROOT/runs/ca" --device "$DEVICE"

# Train SAT-ACT Full on CA.
python neuro/scripts/train_from_config.py \
  --config neuro/configs/ca_satact_full.json \
  --train-dir "$OUTPUT_ROOT/datasets/ca/train" \
  --valid-dir "$OUTPUT_ROOT/datasets/ca/valid" \
  --test-dir "$OUTPUT_ROOT/datasets/ca/test" \
  --cache-dir "$OUTPUT_ROOT/indexes/ca/full" \
  --output-dir "$OUTPUT_ROOT/runs/ca" --device "$DEVICE"
```

### CA archived-checkpoint inference check

This is a small deterministic inference smoke test. It loads the archived Base
and Full checkpoints and sends each model the same two-variable branch query.
It does not evaluate the CA validation split.

```bash
# Check that both archived CA checkpoints load and return a branch prediction.
OUTPUT_ROOT=/path/to/satact-output
DEVICE=cuda

python neuro/scripts/validate_checkpoints.py \
  --checkpoint neuro/checkpoints/ca_satact_base.pt \
  --checkpoint neuro/checkpoints/ca_satact_full.pt \
  --device "$DEVICE" --output "$OUTPUT_ROOT/validation/ca.json"
```

## Solve a CNF with neural-assisted CaDiCaL

This command starts a local inference server for the selected checkpoint, runs
CaDiCaL on one CNF, and lets the solver request neural branching decisions. The
included CNF is only a small end-to-end smoke-test fixture, not a benchmark or
validation dataset.

```bash
# Solve one SAT fixture with the CA Full checkpoint.
OUTPUT_ROOT=/path/to/satact-output
DEVICE=cuda

python solver/solve.py \
  --solver-bin solver/build/cadical-satact \
  --checkpoint neuro/checkpoints/ca_satact_full.pt \
  --cnf solver/fixtures/sat_branch.cnf \
  --output-dir "$OUTPUT_ROOT/solver-validation/ca/full/sat" \
  --device "$DEVICE"
```

## Solver evaluation

Each evaluation command runs the CaDiCaL baseline once and SAT-ACT with three
and five neural calls. The solver uses stable-only mode with lightweight
preprocessing disabled. Group identifiers are also used as solver seeds.

### Benchmark preparation

Create five evaluation groups from the `valid` and `test` splits of the
G4SATBench Medium datasets. Each group contains 100 SAT and 100 UNSAT
instances from each family. The prepared dataset uses symbolic links.

```bash
# Prepare grouped CA, SR, and PS solver-evaluation instances.
CA_SOURCE=/path/to/g4satbench/medium/ca
SR_SOURCE=/path/to/g4satbench/medium/sr
PS_SOURCE=/path/to/g4satbench/medium/ps
EVALUATION_DATA=/path/to/satact-evaluation-data

python solver/evaluation/prepare_benchmark.py \
  --ca-source "$CA_SOURCE" \
  --sr-source "$SR_SOURCE" \
  --ps-source "$PS_SOURCE" \
  --output-dir "$EVALUATION_DATA" \
  --seed 1 --groups 5 --instances-per-label 100
```

### CA evaluation

```bash
# Evaluate the CA Full checkpoint on the validation groups.
EVALUATION_DATA=/path/to/satact-evaluation-data
OUTPUT_ROOT=/path/to/satact-output
DEVICE=cuda

python solver/evaluation/run_evaluation.py \
  --solver-bin solver/build/cadical-satact \
  --checkpoint neuro/checkpoints/ca_satact_full.pt \
  --data-dir "$EVALUATION_DATA" \
  --family ca --split valid --groups 0 1 2 3 4 \
  --neural-calls 3 5 \
  --output-dir "$OUTPUT_ROOT/solver-evaluation" \
  --device "$DEVICE" --workers 8 --timeout 100
```

```bash
# Evaluate the CA Full checkpoint on the test groups.
```
